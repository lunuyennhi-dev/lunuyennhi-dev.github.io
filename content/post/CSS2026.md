## Chrono

### 1. Challenge Description

> "Time is the key - 2026/09/21 14:35:07"

We intercepted a conversation between two people, but their messages were encrypted, making the conversation impossible to understand.

Fortunately, we managed to obtain the ciphertext:

```text
ESUITO{gwfvb_xejqnf_nimgt_b_whhrlv}
```
Can you figure out how the message was encrypted and recover the original text?
Flag format: CSSCTF{...}

### 2. Solution:

We need to decrypt the ciphertext to get the flag, using the given **timestamp** as the key.

The given timestamp is:

```text
Key = '20260921143507'
```

When looking at the ciphertext, we can see that it already has the same format as a flag:

```text
CSSCTF{...}
```

The special characters such as `{`, `}`, and `_` are not changed. Only the letters seem to be encrypted.

Looking at how the letters are changed, we can think of a **Vigenère-like cipher**, where the shift can be different for each letter.

However, the key is a timestamp made up of numbers:

```text
20260921143507
```

So we can try using each digit of the timestamp as the shift value. The key is repeated when we reach the end.

This makes the encryption similar to a **repeating-key Caesar cipher**.

We can write a simple decryption function:

```python
def decrypt_alpha_only(ciphertext: str, key_sequence: list[int]) -> str:
    decrypted = []
    i = 0

    for char in ciphertext:
        if char.isalpha():
            shift = key_sequence[i % len(key_sequence)]
            base = ord('A') if char.isupper() else ord('a')
            decrypted.append(
                chr((ord(char) - base - shift) % 26 + base)
            )
            i += 1
        else:
            decrypted.append(char)
            i += 1

    return "".join(decrypted)


key = [int(x) for x in '20260921143507']

ciphertext = 'ESUITO{gwfvb_xejqnf_nimgt_b_whhrlv}'

print(decrypt_alpha_only(ciphertext, key))
```

The output is:

```text
CSSCTF{fvbsw_qcjohf_lhlcq_b_uhfllm}
```

The first six characters are correct, so the key and the basic idea seem to be correct. However, the text inside the braces is still wrong.

The problem is that we move to the next key number for **every character**.

For example, when we reach `{` or `_`, the key also moves to the next number. But these characters are not encrypted, so they should not change the key position.

Therefore, we try move to the next key number only when the character is a letter.

We can fix this by removing `i += 1` from the `else` block:

```python
def decrypt_alpha_only(ciphertext: str, key_sequence: list[int]) -> str:
    decrypted = []
    i = 0

    for char in ciphertext:
        if char.isalpha():
            shift = key_sequence[i % len(key_sequence)]
            base = ord('A') if char.isupper() else ord('a')
            decrypted.append(
                chr((ord(char) - base - shift) % 26 + base)
            )
            i += 1
        else:
            decrypted.append(char)

    return "".join(decrypted)


key = [int(x) for x in '20260921143507']

ciphertext = 'ESUITO{gwfvb_xejqnf_nimgt_b_whhrlv}'

print(decrypt_alpha_only(ciphertext, key))
```

The output is:

```text
CSSCTF{every_second_hides_a_secret}
```

We got the correct flag!
