## Chrono

### 1. Challenge Description

> "Time is the key - 2026/09/21 14:35:07"

We intercepted a conversation between two people, but their messages were encrypted, making the conversation impossible to understand.

Fortunately, we managed to obtain the ciphertext:

```text
ESUITO{gwfvb_xejqnf_nimgt_b_whhrlv}
```
Can you figure out how the message was encrypted and recover the original text?
Flag format: CSSCTF{...}

### 2. Solution 
We need to decrypt the ciphertext to obtain the flag, using the given **timestamp** as the key.

The given timestamp is:

```text
Key = '20260921143507'
```

Looking at the ciphertext, we can see that it already follows the structure of a flag:

```text
CSSCTF{...}
```

The ciphertext consists mainly of alphabetic characters, while the special characters such as `{`, `}`, and `_` remain unchanged. This suggests that the encryption is applied only to alphabetic characters.

By comparing the ciphertext with the expected flag format and observing that different letters appear to be shifted by different amounts, we can suspect a **Vigenère-like encryption scheme**, where the shift changes according to a repeating key.

However, the key is not a sequence of letters as in a standard Vigenère cipher. Instead, it is a timestamp consisting of digits:

```text
20260921143507
```

This suggests that each digit may be used directly as a Caesar shift. Therefore, the cipher can be described as a **repeating-key Caesar cipher using a numeric key**, similar in principle to a Vigenère cipher.

### Initial attempt

We can write a simple decryption function:

```python
def decrypt_alpha_only(ciphertext: str, key_sequence: list[int]) -> str:
    decrypted = []
    i = 0

    for char in ciphertext:
        if char.isalpha():
            shift = key_sequence[i % len(key_sequence)]
            base = ord('A') if char.isupper() else ord('a')
            decrypted.append(
                chr((ord(char) - base - shift) % 26 + base)
            )
            i += 1
        else:
            decrypted.append(char)
            i += 1

    return "".join(decrypted)


key = [int(x) for x in '20260921143507']

ciphertext = 'ESUITO{gwfvb_xejqnf_nimgt_b_whhrlv}'

print(decrypt_alpha_only(ciphertext, key))
```

The output is:

```text
CSSCTF{fvbsw_qcjohf_lhlcq_b_uhfllm}
```

The first six characters are correct, which confirms that our assumption about the shift-based encryption is likely correct. However, the text inside the braces is still incorrect.

### Finding the problem

The issue is how we advance through the key.

In the first implementation, the key index is incremented for **every character**, including special characters such as `{`, `_`, and `}`.

However, these characters are not encrypted. Therefore, they should not consume a position in the key.

The key should advance **only when an alphabetic character is processed**.

We can fix this by removing `i += 1` from the `else` block:

```python
def decrypt_alpha_only(ciphertext: str, key_sequence: list[int]) -> str:
    decrypted = []
    i = 0

    for char in ciphertext:
        if char.isalpha():
            shift = key_sequence[i % len(key_sequence)]
            base = ord('A') if char.isupper() else ord('a')
            decrypted.append(
                chr((ord(char) - base - shift) % 26 + base
            )
            i += 1
        else:
            decrypted.append(char)

    return "".join(decrypted)
```

Running the corrected code gives:

```text
CSSCTF{every_second_hides_a_secret}
```

Therefore, the flag is:

```text
CSSCTF{every_second_hides_a_secret}
```
